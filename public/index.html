linkpreview

Turn any URL into a clean preview card

One GET request returns the title, description, image, favicon, site name and more — the same metadata Slack, iMessage and Twitter use to unfurl links. Fast, cached, and SSRF-safe. Free to start, no credit card.

One request, everything you need

curl "https://YOUR-HOST/preview?url=https://www.theverge.com&key=YOUR_KEY"
{
  "url": "https://www.theverge.com",
  "resolvedUrl": "https://www.theverge.com/",
  "title": "The Verge",
  "description": "The Verge is about technology and how it makes us feel.",
  "image": "https://www.theverge.com/static-assets/og-image.png",
  "favicon": "https://www.theverge.com/favicon.ico",
  "siteName": "The Verge",
  "type": "website",
  "author": null,
  "publishedTime": null,
  "themeColor": "#5200ff",
  "fetchedAt": "2026-05-29T00:00:00.000Z"
}

Pass your key via ?key=, the x-api-key header, or a Bearer token. Responses are cached and every reply includes X-Quota-Remaining.
